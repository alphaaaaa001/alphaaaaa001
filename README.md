### How I work

I care more about whether a thing is *right* than whether it's clever. If one of my
tools has a hole, I'd rather write the hole down in the README than pretend it isn't there.
### 设计规则

- **可以天马行空，但必须抓住用户15秒注意力窗口** 
- **设计必须服务于体验，不是反过来。** 一个没人用得上的巧妙机关，是负债，不是成绩。
- **对不对，比巧不巧重要。** 我的工具要是有一个洞，我宁可在 README 里把它写出来，也不装作没有。
